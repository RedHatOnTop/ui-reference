# Linear UI Reference

This repository contains a detailed decomposition of the Linear.app user interface design system. It includes extracted CSS values, typography scales, color palettes, and component references intended for recreating the "Linear look" in web projects.

## Documentation contents

- **[Color Palette](https://github.com/Start-Linear-App/ui-reference/blob/main/docs/colors.md)** - Backgrounds, text colors, and semantic tokens.
- **[Typography](https://github.com/Start-Linear-App/ui-reference/blob/main/docs/typography.md)** - Font stack, heading scales, and letter spacing.
- **[Components](https://github.com/Start-Linear-App/ui-reference/blob/main/docs/components.md)** - Button styles, card layouts, and badges.
- **[Screenshots](https://github.com/Start-Linear-App/ui-reference/blob/main/docs/screenshots.md)** - Index of captured visual references.

## Quick Start
To apply the Linear theme basics, import the CSS variables from `docs/colors.md` and set your base font-family to Inter:

```css
body {
  background-color: rgb(8, 9, 10);
  color: rgb(247, 248, 248);
  font-family: "Inter", sans-serif;
}
```
